# UniSearch

UniSearch est une application mobile de **Mots Mêlés (Word Search)** quotidienne.

Chaque jour, les joueurs peuvent compléter deux nouvelles grilles en retrouvant les mots cachés. Les parties sont chronométrées et prennent en compte la précision du joueur.

L'application permet également de jouer hors ligne et de synchroniser automatiquement les parties terminées lorsque la connexion est rétablie.

## Technologies

### Backend

* C# / .NET 8
* ASP.NET Core
* MongoDB
* Docker

### Mobile

* React Native
* Expo
* TypeScript

### DevOps

* Docker / Docker Compose
* GitLab CI/CD
